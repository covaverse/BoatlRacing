# คู่มือเสียงเรือ: ปรับค่าและเปลี่ยนเสียง

ระบบเสียงมี 3 ส่วน แต่ละส่วนปรับคนละที่:

| ส่วน | ไฟล์ | หน้าที่ |
|---|---|---|
| **MetaSound** | `Content/Boats/ThaiLongtail/Audio/MS_LongtailEngine` | เล่นเสียงวน 6 ชั้นพร้อมกัน (เครื่อง 4 ช่วงรอบ + ท่อ + น้ำ) แล้วมิกซ์ออกเป็นเสียงเดียว |
| **Sound Cue** | `SC_LongtailStart`, `SC_LongtailExhaustPop`, `SC_LongtailHit`, `SC_CanalAmbience` | เสียงครั้งเดียว: สตาร์ท, ป๊อปตอนถอนคันเร่ง, ชน และบรรยากาศคลอง |
| **Blueprint** | `Content/Boats/ThaiLongtail/Blueprints/BP_LongtailPhysicsPawn` → ฟังก์ชัน `UpdateEngineAudio` | ทุกเฟรมคำนวณจากรอบ คันเร่ง และความเร็ว ว่าแต่ละชั้นดังเท่าไรและแหลมเท่าไร แล้วส่งค่าเข้า MetaSound |

> **กฎ 3 ข้อ ก่อนแก้อะไร**
> 1. **กด Stop ก่อน** ระหว่าง Play เซฟไม่ได้ และถ้า Compile ระหว่าง Play เรือจะถูกสร้างใหม่กลางเกม
> 2. **ช่องความดังใช้สเกล 0-1** (1 = 100%, 0.3 = 30%) อย่าใส่หลักร้อยหรือพัน เสียงจะแตก
> 3. **อย่าคลิกค้างแล้วลากบนช่องตัวเลข** ค่าจะวิ่งไปไกลมาก ให้ดับเบิลคลิกแล้วพิมพ์ตัวเลขแทน

---

## 0. สลับชุดเสียงเครื่อง (เรือ ↔ รถสปอร์ต)

มี MetaSound 2 ชุด ใช้ค่าและพารามิเตอร์ชุดเดียวกัน จึงสลับได้ทันที:

| ชุด | ไฟล์ | เสียง |
|---|---|---|
| เรือหางยาว | `MS_LongtailEngine` | เครื่องรถแข่ง 4 สูบ + ท่อมอไซค์ ZX-6R |
| **รถสปอร์ต (ใช้อยู่ตอนนี้)** | `MS_SportCarEngine` | V8 Maserati GranTurismo S + ท่อ V12 Ferrari 250 GTO |

วิธีสลับในแมพคลอง: Outliner → คลิกเรือ (`BP_LongtailBuoyancyTrial`) → Details → component **EngineAudio** → **Sound** → เลือก `MS_...` → Save
ถ้าจะสลับให้ทุกแมพ ให้แก้ที่ `BP_LongtailPhysicsPawn` → component EngineAudio → Sound → Compile → Save ด้วย (เรือในแมพคลองตั้งค่าแยกไว้ จึงต้องแก้ทั้งสองที่)
ทั้งสองชุดมีเสียงน้ำเหมือนกัน และปุ่มความดังของแต่ละชุดอยู่ใน MetaSound ของชุดนั้น

## 1. ปรับความดังและเลือกไฟล์เสียง → ใน MetaSound

ดับเบิลคลิก MetaSound ที่ใช้อยู่ (**`MS_SportCarEngine`** หรือ `MS_LongtailEngine`) → ดูแผง **Inputs** ทางซ้าย → คลิกชื่อ input → แก้ **Default Value** ทางขวา → **Save**

| Input | หน้าที่ | ค่าตั้งต้น |
|---|---|---:|
| **Master** | ความดังรวมของเสียงเครื่อง ท่อ และน้ำ (ปุ่มแรกที่ควรปรับ) | 0.4 |
| EngineLevel | ความดังเสียงเครื่องทั้ง 4 ช่วง | 0.9 |
| ExhaustLevel | ความดังเสียงท่อ | 0.7 |
| WaterLevel | ความดังเสียงน้ำ | 0.45 |
| IdleWave / LowWave / MidWave / HighWave | ไฟล์เสียงเครื่องแต่ละช่วงรอบ | เสียงเครื่องจริง |
| ExhaustWave / WaterWave | ไฟล์เสียงท่อ / น้ำ | ZX-6R / น้ำไหล |

input ที่ลงท้ายด้วย `Gain` กับ `Pitch` **ไม่ต้องแก้** Blueprint ส่งค่าเข้ามาเองทุกเฟรม

## 2. ปรับเสียงครั้งเดียว → ใน Sound Cue

ดับเบิลคลิก `SC_...` → Details → **Volume Multiplier** → Save

| Cue | เล่นตอน | ความดังตั้งต้น |
|---|---|---:|
| SC_LongtailStart | เครื่องติดครั้งแรก (กด W ครั้งแรก) | 0.6 |
| SC_LongtailExhaustPop | ถอนคันเร่งหลังเร่งรอบสูง | 0.5 |
| SC_LongtailHit | ชนตลิ่งหรือสิ่งของ ยิ่งชนแรงยิ่งดัง | 0.6 |
| SC_CanalAmbience | ตลอดเวลาในแมพคลอง | 1.0 |

อยากให้เสียงชนสุ่มหลายแบบ: เปิด Cue แล้วเพิ่ม node **Random** ต่อ Wave Player หลายตัว (Kenney มีไฟล์ไม้กระแทก 5 แบบ) หรือเพิ่ม **Modulator** ให้ pitch และความดังต่างกันเล็กน้อยทุกครั้ง
เสียงนกในคลองปรับได้อีกที่: Outliner ของแมพ → โฟลเดอร์ Audio → `CanalAmbience` → **Volume Multiplier** (0.35)

## 3. ปรับพฤติกรรมเสียง → ใน Blueprint ของเรือ

เปิด `BP_LongtailPhysicsPawn` (ไม่ใช่ `BP_ThaiLongtailBoat` ซึ่งเป็นแค่โมเดล) → **Class Defaults** → ค้นหา **Audio** → แก้ → **Compile** → **Save**

### Audio › Engine
| ค่า | ความหมาย | ค่าตั้งต้น |
|---|---|---:|
| **GearSpeedKmh** | ความกว้างช่วง "เกียร์" ของเสียง (0-15, 15-30, 30-45 …) ใส่มากขึ้น เช่น 20 ช่วงจะยาวขึ้นและเปลี่ยนเกียร์น้อยลง | 15 |
| GearLowRPM | รอบเสียงตอนเริ่มแต่ละช่วง (หลังเปลี่ยนเกียร์) | 2400 |
| GearHighRPM | รอบเสียงตอนท้ายแต่ละช่วง (ก่อนเปลี่ยนเกียร์) | 5600 |
| **SoundBlendSpeed** | ความนุ่มตอนเสียงเปลี่ยน: น้อย = ไหลช้านุ่ม (3), มาก = ไวกระชับ (12) | 6 |
| EngineIdleRPM / LowRPM / MidRPM / HighRPM | **รอบที่ไฟล์เสียงแต่ละช่วงถูกอัด** ต้องเรียงจากน้อยไปมาก ห้ามเป็น 0 | 1500 / 2400 / 3600 / 5600 |
| EngineStartSound | Cue เสียงสตาร์ท | SC_LongtailStart |

### Audio › Exhaust
| ค่า | ความหมาย | ค่าตั้งต้น |
|---|---|---:|
| ExhaustLoopRPM | รอบที่ไฟล์ท่อถูกอัด | 4300 |
| ExhaustPopMinRPM | รอบขั้นต่ำที่ถอนคันเร่งแล้วจะมีป๊อป | 3500 |
| ExhaustPopSound | Cue เสียงป๊อป | SC_LongtailExhaustPop |

### Audio › Water และ Audio › Hit
| ค่า | ความหมาย | ค่าตั้งต้น |
|---|---|---:|
| WaterFullSpeedKmh | ความเร็วที่เสียงน้ำดังและแหลมสุด | 110 |
| HitSound | Cue เสียงชน (ชนเบากว่าแรงราว 0.45 ม./วิ จะเงียบ) | SC_LongtailHit |

หมวด **Audio › Internal** เป็นค่าที่ระบบใช้เอง ไม่ต้องแก้

## เสียงทำงานยังไง

- **เกียร์เสียง:** ในแต่ละช่วงความเร็ว (`GearSpeedKmh`) รอบเสียงไต่จาก `GearLowRPM` ขึ้นไป `GearHighRPM` พอข้ามไปช่วงถัดไป รอบตกกลับลงมาเหมือนเข้าเกียร์ใหม่ ตอนเรือเกือบหยุด (ต่ำกว่า 3 กม./ชม.) ใช้รอบจริงของเครื่อง (เดินเบา หรือกด W+Space เร่งอยู่กับที่)
- **เบลนด์:** รอบเสียงและคันเร่งค่อยๆ ไหลเข้าหาค่าใหม่ด้วยความเร็ว `SoundBlendSpeed` ตอนเปลี่ยนเกียร์หรือปล่อยคันเร่ง เสียงจึงไหลไม่กระโดด
- **4 ช่วงรอบ:** ยิ่งรอบเสียงสูงยิ่งส่งต่อจากช่วงต่ำไปช่วงสูงแบบ crossfade แต่ละช่วงยืด pitch ตามรอบ ÷ รอบที่อัด
- **ท่อ:** ดังขึ้นตามคันเร่ง และ pitch ตามรอบเสียง
- **น้ำ:** ดังและแหลมขึ้นตามความเร็ว

## เปลี่ยนเป็นเสียงชุดใหม่

- **ไฟล์เดิมทับ:** คลิกขวา `SW_...` ใน `Boats/ThaiLongtail/Audio` → **Reimport With New File** (ติ๊ก Looping ให้เสียงวน)
- **ชี้ไปไฟล์อื่น:** เลือกไฟล์ใหม่ใน input `...Wave` ของ MetaSound
- **เสียงเครื่องหลายรอบ** (sample pack ที่ตั้งชื่อเป็น 2000rpm / 4000rpm …): ใส่ทีละช่วง แล้วตั้ง `EngineIdleRPM`…`EngineHighRPM` ให้ตรงกับรอบที่อัด
- **สร้าง MetaSound ใหม่:** `Tools/create_boat_audio_assets.py` สร้าง MetaSound และ Sound Cue ที่ยังไม่มีจากไฟล์ `SW_...` เพิ่มชุดเสียงใหม่ได้ที่ `PROFILES` (ไฟล์ช่วงรอบต้องปรับ pitch ให้ตรง 1500 / 2400 / 3600 / 5600 และท่อ 4300) อยากสร้างชุดเดิมใหม่ ให้ลบ MS_ ตัวนั้นก่อน

## ข้อจำกัด

- ค่าทั้งหมดยืนยันจากการอัดเสียงที่ UE ส่งออกจริง: คันเร่งสุด -19.5 dBFS (เรือ) / -20 dBFS (รถสปอร์ต) ยอดสูงสุด 0.38 ไม่มีเสียงแตก ตอนเดินเบาบนน้ำ -24 dBFS แต่จุดตัดของไฟล์เลือกจากการวิเคราะห์ ไม่ได้ฟังด้วยหู
- เรือเร่ง 0-100 กม./ชม. ในราว 3 วินาที ช่วงเกียร์ 15 กม./ชม. จึงผ่านเร็วมาก ถ้าอยากได้ยินแต่ละเกียร์นานขึ้น ให้เพิ่ม `GearSpeedKmh`
- เสียงชนเล่นที่ตำแหน่งเรือ ไม่ใช่จุดที่ชน ไม่มีชุดเสียงแยกตอนเร่งกับตอนผ่อน
- ชุดรถสปอร์ต: ช่วง Low และ High ถูกปรับ pitch ขึ้นราว 5 semitone จากที่อัดจริง ถ้าฟังแล้วแหลมเพี้ยนไป บอกให้หาช่วงอื่นมาแทนได้
