## ทดลองขับ

1. เปิด `.uproject` ด้วย UE 5.8.3; แผนที่เริ่มต้นคือ `/Game/Maps/M_WaterPhysicsTest`.
2. กด Play และคลิก viewport เพื่อรับคีย์บอร์ด: `W/S` ขับหน้า/ถอย, `A/D` เลี้ยว, `Q/E` ลด/ยกแกนใบพัด, `Space` ปลดคลัตช์, `C` เปลี่ยนกล้อง.
3. Free Orbit ตามเรือและหมุนมองรอบเรือได้ ไม่ใช่ spectator ที่บินแยกจากเรือ.
4. จูนค่าที่ Data Asset แล้วหยุด/เริ่ม Play ใหม่ เพราะ Pawn โหลด Handling ตอน BeginPlay.

งานนี้ยังเป็นต้นแบบขับได้ ไม่ใช่เกมแข่งเรือพร้อมจำหน่าย น้ำทะลุห้องเรือ คลื่นสูง และการจูนแรงเฉื่อยตามเวลาจำลองยังเป็นงานเปิด ดู STATUS ก่อนสรุปผลทดสอบ.
