# น้ำและฟองสไตล์อนิเม — 5 ตุลาคม 2026

ชุดแรกเปลี่ยนสีและลด normal แต่ยังเห็นเงาสะท้อนและรายละเอียดแบบน้ำสมจริง จึงยังอ่านเป็นอนิเมไม่ชัด ชุดใหม่เพิ่มกลุ่มสีใหญ่ ผิวด้าน และไฮไลต์ฟ้าอ่อนแบบภาพวาดบน SingleLayerWater เดิม เพิ่มน้ำหนักสีที่ผิวเพื่อให้พาเลตแสดงจริง คลื่นแหวกน้ำและฟองสะสมยังใช้ซิมเดิม

## เปิดสไตล์และปรับหน้าตาน้ำ

Content → Water → Materials → BoatContact → **MI_WaterBoatOcean** → กลุ่ม **Anime Water - Look**

ติ๊ก override ของค่าที่ต้องการ ใส่ตัวเลข กด Enter แล้ว Save กลุ่มนี้เปลี่ยนหน้าตาน้ำได้แม้เรือจอด ค่าที่บันทึกใน Ocean คือ **AnimeStyleStrength = 1**

| ค่า | ผลและวิธีลอง | ค่าตั้งต้นใน Ocean |
|---|---|---:|
| AnimeStyleStrength | 0 = น้ำเดิม, 1 = ผิวภาพวาดเต็ม; 0.5 ผสมครึ่งหนึ่ง ลอง 0 กับ 1 เพื่อเห็นผลชัด | 1 |
| AnimeWaveScaleCm | ความยาวลายไฮไลต์ หน่วย ซม. เพิ่มแล้วลายกว้างขึ้น ลอง 150 กับ 1000 | 500 |
| AnimeHighlightGain | ความแรงของไฮไลต์ฟ้าอ่อน; 0 ซ่อนไฮไลต์ภาพวาด ลอง 0 กับ 1 | 0.7 |
| AnimeWaveSpeed | ความเร็วเลื่อนลาย หน่วย ซม./วินาที; 0 หยุดลาย ไม่มีผลต่อความเร็วเรือหรือแรงคลื่นจริง | 12 |
| AnimeDeepColor | สีส่วนเข้มของผิว รวมถึงสีที่ใช้มากขึ้นในระยะไกล | RGB 0.025 / 0.18 / 0.30 |
| AnimeWaterColor | สีหลักของผิวน้ำ | RGB 0.045 / 0.42 / 0.52 |
| AnimeHighlightColor | สีไฮไลต์ภาพวาด ใช้ฟ้าอ่อนเพื่อแยกจากฟองขาว | RGB 0.38 / 0.75 / 0.78 |

สีในตารางเป็น Linear RGB ลายสีวางใน world space และเลื่อนตาม AnimeWaveSpeed การเพิ่ม WaveScale ทำให้ลายใหญ่ขึ้น ไม่ได้เพิ่มขนาดคลื่นที่เรือสร้าง ส่วนที่ยกตัวจากซิมจริงยังมีสีเน้นเล็กน้อย

เมื่อ Style = 1 ระบบใช้ roughness ผิวประมาณ 0.52, specular 0.08 และเพิ่ม opacity ของ SingleLayerWater ให้พาเลตผิวมองเห็น ฟองมีผิวด้านขึ้นและสีขาวตาม AnimeFoamTint ค่า **Water Roughness / Water Fresnel Roughness / Water Specular** เดิมจึงมีผลเพียงบางส่วนเมื่อผสมสไตล์ ตั้ง **AnimeStyleStrength = 0** ก่อนเทียบผลของสามค่านี้

## สีและลายฟอง

อยู่ที่ **MI_WaterBoatOcean** → กลุ่ม **Anime Water** ช่องติ๊กเปิด override ไม่ได้สร้างฟองเอง ต้องขับให้เกิดคลื่นและรอยฟองก่อนจึงเห็นผล

| ค่า | เพิ่มแล้วเป็นอย่างไร | ลองเทียบ | ค่าตั้งต้น |
|---|---|---|---:|
| AnimeFoamTint | เปลี่ยนสีฟองบนผิวน้ำ | ขาวกับฟ้าอ่อน | RGB 0.82 / 0.96 / 1 |
| FoamBreakup | ลายโปร่งและขอบแตกมากขึ้น | 0 กับ 0.65 | 0.28 |
| FoamPatternScale | ก้อนหรือลายฟองใหญ่ขึ้น | 0.5 กับ 3 | 1.8 |
| WakeFoamGain | ฟองสะสมในรอยเรือขาวขึ้น; 0 ซ่อนส่วนนี้ | 0 กับ 1 | 0.95 |
| WaveFoamGain | ฟองยอดคลื่นที่เรือสร้างมากขึ้น; น้ำเรียบไม่เปลี่ยน | 0 กับ 1 | 0.22 |

ไฮไลต์ฟ้าอ่อนจากกลุ่ม Look กับฟองขาวเป็นคนละส่วน ฟองยังเกิดจากคลื่นจริงและประวัติใน RT เมื่อ Style = 1 จะจัดสีฟองเป็นก้อนที่อ่านง่ายขึ้นโดยไม่เปลี่ยนเงื่อนไขเกิดและอายุฟอง

WakeFoamGain = 0 ยังอาจเห็นฟองจาก WaveFoamGain และสเปรย์ Niagara ตั้ง WaveFoamGain = 0 ด้วยเมื่อต้องการเทียบผิวที่ไม่มีฟองจากสองส่วนนี้ gain จำกัด 0–1, Breakup 0–0.7, PatternScale อย่างน้อย 0.25 ค่าที่เกินช่วงไม่เพิ่มผลต่อ

## เงื่อนไขเกิดและอายุฟอง

เปิด **MI_BoatFoamComposite** ซึ่ง Blueprint ใช้สร้าง FoamCompositeMID ตอนเริ่มเล่น

| ค่า | เพิ่มแล้วเป็นอย่างไร | วิธีลอง |
|---|---|---|
| FoamBreakingThreshold | ต้องเป็นคลื่นชันขึ้นจึงเริ่มเกิดฟอง | เริ่ม 0.12; 0.06 ขึ้นง่าย / 0.25 ต้องแรงขึ้น |
| Birth | เพิ่มฟองเมื่อผ่านเงื่อนไขคลื่นแตก | เพิ่มทีละน้อย; น้ำเรียบยังไม่เกิดฟอง |
| Decay | ฟองจางเร็วขึ้น | ลดเมื่ออยากให้รอยฟองอยู่นาน |
| Diffusion | รอยฟองกระจายและนุ่มขึ้น | เพิ่มน้อย ๆ เพื่อไม่ให้เป็นปื้น |
| NoiseAmount | การไหลวนและขอบรอยแตกมากขึ้น | มากเกินไปจะดูไหลมั่ว |
| SurfaceFlowCmPerSec | ทิศทางไหลใน world XY หน่วย ซม./วินาที | R = X, G = Y; 0/0 ปิดการไหลส่วนนี้ |

ระบบใช้ความชันกับความสูงบวกจาก **NormalRT ของ BP_FluidSim_01** เริ่มสะสมฟองหลังส่วนหัวเรือ เมื่อหยุดจะหยุดเพิ่มฟอง แต่ฟองเดิมยังไหลและค่อย ๆ จาง เป็นเงื่อนไขภาพจากซิมผิวสองมิติ ไม่ใช่การจำลองฟองอากาศแบบปริมาตร

SurfaceFlow เป็นทิศทางที่ตั้งไว้ ยังไม่ได้เชื่อมกับลมของระบบสภาพอากาศอัตโนมัติ รอยเลี้ยวเกิดจากประวัติฟองใน world space และการไหลวน

## คลื่นและผิวเดิม

**Fluidsim Normal Strength** ยังควบคุมเงาและความเอียงจากคลื่นจริง ส่วน Default Near/Distant Normal Strength คุมรายละเอียดผิวพื้นฐาน ลดเมื่ออยากให้ผิวสะอาดขึ้น

แรงและความสูงคลื่นอยู่ใน [คู่มือแรงแหวกน้ำ](2026-10-05-water-surge-tuning.md) เริ่มที่ Fluid Displacement Multiplier **3** และ Max Fluid Displacement **40 ซม.** สไตล์ภาพวาดไม่เปลี่ยนสองค่านี้

เมื่อตั้ง Style = 0 กลับไปปรับ Water Albedo, Scattering และ Absorption ของน้ำเดิมได้เต็มที่ **Absorption ในกราฟนี้ใช้ค่ากลับด้าน 1/RGB/Alpha**: ตัวเลขช่องสีมากขึ้นจึงปล่อยสีนั้นผ่านได้ไกลขึ้น หลีกเลี่ยงค่า 0 และทดลองทีละช่อง

## วิธีเทียบและสถานะตรวจสอบ

ใช้มุมกล้องเดิม เทียบ Style 0 กับ 1 ก่อน จากนั้นปรับ WaveScale, HighlightGain และสีทีละตัว ขับด้วยความเร็วใกล้กันเมื่อตรวจฟองและคลื่น

การตรวจชุดภาพวาดใหม่ยังรอผลจาก `Tools/verify_anime_water_look.py` ซึ่งจะบันทึก `Saved/Automation/BoatContact/anime-look-gpu-check.json` ตรวจการผสม Style, การเปลี่ยนพาเลตและขนาดลายบน GPU รวมถึงสาย Normal และ WorldPositionOffset ของซิมเดิม

ผลตรวจระบบฟองก่อนเพิ่มชุดภาพวาดอยู่ใน `wave-driven-foam-check.json`, `foam-turn-cut-check.json` และ `live-wave-foam-check.json` ในโฟลเดอร์เดียวกัน ต้องอ่านแยกจากผลตรวจสไตล์ใหม่ การทดสอบ shader ยืนยันการทำงานของค่า ส่วนความสวยต้องดูจากภาพในเกมด้วย
